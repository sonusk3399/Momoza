# 🍜 Momoza — Restaurant & Cafe Website

A modern and responsive **Restaurant & Cafe landing page** built using HTML and CSS.
The website is designed with a stylish food-focused UI, responsive layouts, image-based sections, hover effects, and scroll animations.

## 🌐 Live Preview

👉 Add your live website link here

`https://sonusk3399.github.io/Momoza/`

## 📌 About The Project

**Momoza** is a modern restaurant and cafe website concept created to showcase a premium food and dining experience.

The website includes:

* 🏠 Attractive Hero Section
* 🍜 Specialist Cuisine Section
* 📖 About Us / Our Story Section
* 📊 Restaurant Statistics Section
* ✨ Hover Effects
* 🎬 Scroll Animations
* 📱 Mobile Responsive Design
* 🖼️ Food and Restaurant Images

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **AOS (Animate On Scroll)** — Scroll animations
* **Google Fonts** — Custom typography

## 📱 Responsive Design

The website is optimized for different screen sizes using CSS media queries.

It includes responsive layouts for:

* Desktop 💻
* Tablet 📱
* Mobile 📱

The mobile navigation and content sections are adjusted for smaller screens.

## 🎬 Animations

The website uses **AOS (Animate On Scroll)** for smooth scroll-based animations.

Example configuration:

```javascript
AOS.init({
    duration: 1200,
    easing: 'ease-in-out',
    once: true,
    offset: 150,
    delay: 100
});
```
